# Expert Listing v0.1.0

Expert Listing is a Flutter mobile experience for browsing and discussing Lagos
real-estate posts. It uses a Hono HTTP API with relational PostgreSQL data and
public media hosted by Supabase.

## Highlights

- Network-first social feed with pull-to-refresh, cursor pagination, filters,
  bounded media loading, and an explicitly labelled saved-feed fallback.
- Persistent likes and flat comments, native text sharing, local bookmarks,
  full-screen property imagery, liker previews, and latest-comment previews.
- Property search with bounded recent searches, a paginated property catalog,
  and server-backed profiles.
- Four fixed public demo personas for reviewing persona-specific likes,
  feed state, and profiles without a production authentication flow.
- System-driven light and dark themes, platform-appropriate controls, reduced
  motion handling, accessible labels, and ordinary 48 by 48 logical-pixel tap
  targets.

## Install on Android

1. Download `expert-listing-v0.1.0-android.apk` and `SHA256SUMS.txt` from this
   release.
2. Verify the download from the directory containing both files:

   ```sh
   shasum -a 256 -c SHA256SUMS.txt
   ```

3. Allow installation from the app used to open the APK when Android requests
   it, then open the APK and choose **Install**.

For a connected development device, installation can instead use:

```sh
adb install expert-listing-v0.1.0-android.apk
```

## Scope notes

- This assessment build intentionally has no registration, login, email
  verification, payments, messages, maps, GPS, or geocoding.
- The persona selector is deliberate unauthenticated demo impersonation and is
  limited to four server-advertised fixture aliases. It is not a production
  identity model.
- Bookmarks are device-local and are not synchronized to the backend.
- Story viewing and creation, arbitrary property-detail navigation, and other
  unavailable destinations return honest boundary notices instead of fake
  success.
- General, request, and property post creation with image upload remains outside
  the `v0.1.0` release and is not claimed as complete.
- TestFlight is an optional delivery channel and does not replace the Android
  release.
