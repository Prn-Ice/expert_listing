# Expert Listing

Expert Listing is a Flutter assessment for a Lagos real-estate social feed. It
uses a Hono API and PostgreSQL on Supabase.

**Status:** the repository contains the relational schema, deterministic seed
fixtures, Hono read-path API, and Flutter M4 network-first feed. The Flutter
feed has automated analyze and test evidence; create-post, engagement, signed
APK, visual-overlay, and named-device evidence remain incomplete or unverified.
